# Производственная практика ПМ.05

Проектирование и разработка информационных систем. Группы РВМП, 7 семестр, 2026–2027 учебный год.

[Открыть учебный сайт](https://olgakraven.github.io/2026-2027-09.02.07-rvmp-pp-pm.05-sem07/).

Практика посвящена сервисной информационной системе: требованиям, проектированию БД, регистрации, разграничению доступа, обработке заявок, транзакциям, истории и тестированию. Подготовлены 30 предметных областей и отдельная демонстрационная область.

На сайте доступны подробная методичка, PDF задания и инструкции, общий шаблон отчёта и демонстрационный проект Flask/PHP с SQL-схемой. Пример предназначен для сверки после самостоятельной разработки. При сдаче проекта приложите ссылку на его репозиторий.

Исходники демонстрации и схема находятся в demo/, единый источник учебного содержания — content/course.json. Публикуемый комплект расположен в site/.

Навыки сопоставлены с заданием 1 базового образца демонстрационного экзамена КОД 09.02.07-3-2027. Предметные области и дополнительные проверки являются авторской учебной адаптацией, а не официальным экзаменационным заданием. Ссылка на источник приведена в учебных материалах.

Демонстрация фактически проверена на macOS с MySQL, Python/Flask и PHP/PDO. Команды Windows приведены в руководстве; отдельный запуск на Windows в эту проверку не входил. Все данные примера вымышленные.
