# 26. Ремонт погрузочных тележек

Исходные данные своего проекта. Серверные файлы создаются по выбранной инструкции Flask или PHP; выполнять демонстрационную область отдельно не требуется.

Грузоподъёмность должна быть положительным целым числом.

В domain.json описаны поля, но rules оставлен пустым для самостоятельной реализации условия. Для правил диапазона, pattern или choices проверить параметры самих fields. Объяснить решение и добавить собственный соседний случай. case.json содержит данные проверки, а не серверную реализацию.

Создать отдельную пустую БД pm05_v26, выполнить schema.sql. Не импортировать поверх рабочей БД. Заменить domain.json и schema.sql образца этими файлами до первого запуска. Не менять статусные и регистрационные ограничения.
