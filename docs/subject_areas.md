### Назначение и собственные данные
Организация оказывает услуги в области «Ремонт ноутбуков». Клиент передаёт изделие, описывает неисправность, выбирает услугу и просматривает свои заявки. Подберите две реальные по смыслу услуги и двух вымышленных исполнителей, обозначьте их в своём справочнике. Для начальной заявки используйте обозначение изделия «Учебное изделие 01», неисправность «Требуется диагностика заявленного дефекта», клиента «Учебный Клиент», почту client@example.test. Конкретные модель, тип и допустимые значения заполните согласованно с областью, без реальных персональных данных.

### Поля и точность измерений
serial — Серийный номер: text
adapter — Блок питания: Да / Нет

### Индивидуальное правило
При выборе диагностики питания сведения о блоке питания обязательны. Для положительных чисел принята точность 0,1 дюйма или 0,01 кг/мм, для целых — единица; верхняя граница 100000, если в поле не задана более узкая. Это уточнение учебного набора. ### Корректный запрос
```
{
  "equipment": "Учебное изделие 01",
  "symptom": "Требуется диагностика заявленного дефекта",
  "service_id": "1",
  "serial": "EDU-105",
  "adapter": "Да"
}
```

### Ошибочный запрос
```
{
  "equipment": "Учебное изделие 01",
  "symptom": "Требуется диагностика заявленного дефекта",
  "service_id": "1",
  "serial": "EDU-105",
  "adapter": ""
}
```

### Маршрут и собственная проверка
Спроектировать ER → создать БД → реализовать выбранный сервер → зарегистрировать клиента → воспроизвести ошибку → исправить своё правило → создать корректную заявку → обработать администратором → оставить отзыв владельцем → проверить чужой доступ и чистый повтор. Для числового поля проверить нижнюю/верхнюю допустимые границы, значения сразу вне границ и дробь при integer. Для выбора — каждое допустимое значение и неизвестную строку; для условной обязательности — пустое, допустимое, другую услугу. Добавить собственный соседний случай, которого нет в case.json.

Сохранить собственные ER, ввод и отказ, исправленную заявку, прямой чужой запрос, историю из трёх событий, отзыв и чистый повтор.
